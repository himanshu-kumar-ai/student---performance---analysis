# Student Performance Data Analysis

A beginner-friendly data analysis project using Python.

## Objective
Analyze student marks, attendance, subject performance, and performance groups to identify useful insights.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Features
- Data cleaning and preprocessing
- Statistical analysis
- Subject-wise performance analysis
- Student performance visualization
- Attendance vs marks analysis
- Performance group classification
- Data-driven recommendations

## Project Files
- `student_performance_analysis.ipynb` — Complete analysis and visualizations.
- `student_performance_cleaned.csv` — Cleaned dataset.

## How to Run
Open the notebook using Google Colab or Jupyter Notebook.

## Learning Outcome
Practiced data cleaning, exploratory data analysis, visualization, and extracting insights using Python.
